# Presets de fábrica

Todos empiezan desde el mismo conjunto neutral de ocho bandas. Cada preset modifica solamente las bandas; conserva OUTPUT, bypass, comparación de nivel y contexto. Los valores siguientes son cambios respecto a NEUTRO.

| Preset | Cambios |
|---|---|
| NEUTRO | Cortes desactivados y ganancias a cero |
| RAP GRAVE - CLARIDAD | Pasa altos 65 Hz; campana 280 Hz −2 dB/Q1,2; 3 kHz +1,5 dB/Q0,9 |
| RAP - PRESENCIA | Pasa altos 75 Hz; 280 Hz −1,5 dB/Q1,2; 3 kHz +2 dB/Q0,9 |
| VOZ OSCURA - ABRIR | 3 kHz +1,5 dB/Q0,9; high shelf 10 kHz +2 dB |
| VOZ NASAL - SUAVIZAR | Campana 1,4 kHz −2 dB/Q1,5 |
| VOZ BRILLANTE - CONTROL | Campana 5,5 kHz −2 dB/Q1,5; high shelf 10 kHz −1 dB |
| CANTO MELODICO - SUAVE | Pasa altos 60 Hz; 280 Hz −1 dB/Q1,2; high shelf 10 kHz +1 dB |

No hay un preset correcto para todas las voces graves o nasales. Elige uno, compara al mismo volumen y reduce o desactiva lo que no mejore tu toma. Los nombres describen la intención del ajuste, no una clasificación automática del cantante. No se anuncian como presets oficiales de artistas.
